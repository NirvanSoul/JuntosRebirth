| Elemento                                            | Tipo                                                                                        | Obligatorio para usar la app                           | Dónde se gestiona                                                                                         | Estado                                                                            |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Términos de servicio                                | Aceptación contractual                                                                      | Sí, para crear una cuenta (no para usar como invitado) | Pendiente de pantalla de registro; contenido ya escrito en `src/features/legal/content/termsOfService.ts` | Contenido listo, aceptación aún no se registra porque no existe flujo de registro |

## Reglas aplicadas

- Un único checkbox genérico de "Acepto todo" no sustituye estos consentimientos separados (§3 del documento legal).
- No se pide ningún permiso de sistema que la app no use: no hay filas de cámara, fotos, contactos ni ubicación en `PermissionsScreen` porque no se solicitan esos permisos.
- El consentimiento de anuncios no se mezcla con la aceptación de términos (§50 del documento legal, "No mezclar ads consent con términos").
